# เว็บไซต์จดหมายวันครบรอบ (Anniversary Envelope Web App) 💌

เว็บแอปพลิเคชันซองจดหมายเปิดอ่านสุดโรแมนติก ออกแบบมาเป็นพิเศษสำหรับมอบให้แฟนในวันครบรอบ หน้าเว็บสะอาด สวยงาม และไม่มีปุ่มเมนูหรือปุ่มควบคุมเสียงมารบกวนสายตา

---

## 🌟 ฟีเจอร์เด่น (Features)

1. **ซองจดหมาย 3D แบบโต้ตอบ (Interactive 3D Envelope):**
   - มีตราประทับขี้ผึ้งสีแดงรูปหัวใจ (Wax Seal) พร้อมเอฟเฟกต์ประกายระยิบระยับ
   - เมื่อกดที่ซองหรือตราประทับ ฝาซองจะพับเปิดออกในรูปแบบ 3D และตัวจดหมายจะเลื่อนขึ้นมา
   - ตัวจดหมายจะขยายเต็มจอให้อ่านได้อย่างสบายตา ทั้งบนมือถือและคอมพิวเตอร์
   - สามารถกด "พับเก็บใส่ซอง ✉️" เพื่อพับกลับเข้าซองได้ทุกเมื่อ

2. **แกลเลอรีรูปถ่ายโพลารอยด์ (Polaroid Memories):**
   - จัดแสดงรูปคู่พร้อมเทปแปะน่ารักและข้อความใต้ภาพ

3. **ปุ่มขอกอดและหัวใจระเบิด (Interactive Hug & Love Counter):**
   - กดปุ่ม "ขอกอด 1 ที 💕" จะมีเสียงกระดิ่งใส พร้อมอีโมจิความรักลอยกระจายรอบจอ และเก็บสถิติจำนวนครั้งที่กอด

---

## ✏️ วิธีปรับแต่งข้อความ วันที่ และรูปภาพ

คุณสามารถเปิดไฟล์ `script.js` แล้วแก้ไขข้อมูลที่ส่วนบนสุด (`ANNIVERSARY_CONFIG`) ได้ง่ายๆ ดังนี้:

```javascript
const ANNIVERSARY_CONFIG = {
  // 1. ชื่อแฟน (ผู้รับ)
  receiverName: "คุณแฟนตัวเล็ก",

  // 2. ชื่อของคุณ (ผู้ส่ง)
  senderName: "จาก... คนที่รักเธอที่สุดในโลก",

  // 3. หัวข้อจดหมาย
  letterTitle: "Happy Anniversary นะครับที่รัก 💕",

  // 4. วันที่เริ่มคบกัน (รูปแบบ: ปี-เดือน-วัน ค.ศ. เช่น "2025-02-14")
  startDate: "2025-02-14",

  // 5. ข้อความในจดหมาย
  letterBody: `พิมพ์ข้อความของคุณที่นี่...`,

  // 6. รูปภาพโพลารอยด์ 3 รูป (ใส่ URL หรือใส่ชื่อไฟล์รูปในโฟลเดอร์เดียวกัน)
  photo1: "https://...",
  caption1: "คำบรรยายใต้รูป 1",
  photo2: "https://...",
  caption2: "คำบรรยายใต้รูป 2",
  photo3: "https://...",
  caption3: "คำบรรยายใต้รูป 3"
};
```
